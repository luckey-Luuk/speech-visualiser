Github project for unpublished paper: Phoneme Classification of Real Time Magnetic Resonance Imaging Using 3D Convolutional Neural Network

Project by: 
Thomas, Simone and Justin
MSc students Leiden University
Course: Audio Processing and Indexing 2025

This git repository includes the working files and results for the afformentioned paper. These include the scripts for data sampling, data pre-processing, 3D CNN model architecture, model training and data analysis. The data model used, USC-TIMIT, is not included. 

To run the jupyter notebook scripts, install the requirements in requirements.txt in a python environment. To run, open the clean script in software of choice and run using a notebook kernel. A minimum of 16GB of RAM is required. 

For usage, fix the necessary variables to the local data location. Run the appropriate code blocks in sequence. The CNN model can be stopped and started using a checkpoint system.
